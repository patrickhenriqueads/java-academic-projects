# 🎓 Academic Java Projects / Projetos Acadêmicos de Java

---

## 🇺🇸 English Version

### 📌 About the Repository
This repository contains my academic projects, programming exercises, and laboratory assignments developed during my college degree. The codes are built using modern features of **Java 21+** inside **IntelliJ IDEA 2025**.

### 🛠️ Technologies & Features
- **Language:** Java (JDK 21 or higher)
- **IDE:** IntelliJ IDEA 2025
- **Concepts:** Clean structure using *Implicitly Declared Classes* and *Instance Main Methods* (`void main()` without explicit classes).

### 📂 Repository Structure
The projects are organized dynamically into folders according to the university assignments:
- `ListaXX/`: Folders containing the exercises from each assignment list passed by the professor.
